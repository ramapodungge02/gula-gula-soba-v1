## Landing Page Gula-Gula Soba

Website sederhana yang di buat khusus untuk mengenalkan kuliner tradisional Gorontalo.

### 1. Teknologi yang digunakan

- HTML
- CSS
- Javasript

### 2. Cara menjalankan website

1. Clone repository
2. Buka folder `gula-gula-soba`
3. Buka file `index.html` di browser

### 3. Struktur folder

- `css/`: berisi file CSS
- `img/`: berisi file gambar
- `js/`: berisi file Javascript
- `index.html`: berisi file HTML

### 4. Kontribusi

1. Fork repository
2. Buat branch baru (misal: `feature/add-new-feature`)
3. Commit perubahan
4. Push branch
5. Buat Pull Request
